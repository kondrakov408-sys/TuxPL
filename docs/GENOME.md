# Геномная модель и детерминированная энтропия в TuxPL 2.0.0

## 1. Геном программы (`TuxGenome`)

Каждая программа в TuxPL 2.0.0 обладает четырьмя 64-битными хромосомами:
- **$G_0$**: хромосома контекстного декодера и первичного смешивания.
- **$G_1$**: хромосома динамической ширины инструкций и смещения для взрослых ячеек (`ADULT`).
- **$G_2$**: хромосома старения (`OLD`) и адресации контекста B.
- **$G_3$**: хромосома фонового резонанса спящих ячеек (`Dormant Resonance`).

## 2. Формулы эволюции генома (`tux_genome_evolve`)

После каждого шага исполнения (фаза 6) геном эволюционирует на основе полученных результатов:
$$G_{next}[0] = \text{tux\_crazy64}(G[0] \oplus \text{result}, \text{Entropy.pool})$$
$$G_{next}[1] = \text{tux\_crazy64}(G[1] \oplus G_{next}[0], \text{Registers}[1])$$
$$G_{next}[2] = \text{tux\_crazy64}(G[2] \oplus \text{PC\_CODE}, G_{next}[1])$$
$$G_{next}[3] = (G[3] \ggg 13) \oplus G_{next}[0] \oplus G_{next}[2]$$

## 3. Математика `tux_crazy64`

Функция `tux_crazy64` расширяет 32-битную операцию Malbolge CRAZY на 64 бита:
- Преобразование выполняется в двух 20-тритных блоках с использованием матрицы `CRAZY_TRIT[3][3]`.
- Старший и младший результаты сдвигаются и смешиваются перекрёстными побитовыми операциями.
- Функция строго детерминирована, некоммутативна и не имеет вырожденных состояний.

## 4. Пул энтропии и шаг энтропии (`tux_entropy_step`)

Пул энтропии обновляется синхронно с шагом программы:
$$\text{Entropy.pool} = \text{tux\_crazy64}(\text{Entropy.pool} \oplus \text{pc}, G_0 \oplus \text{regs}[0])$$

## 5. Оверрайды для детерминированного тестирования

Для 100% воспроизводимости тестов рантайм поддерживает строгие переменные окружения:
- **`TUX_ENTROPY_SEED=<uint64>`**: задаёт фиксированный сид энтропии, не меняя паспорт программы.
- **`TUX_GENOME=<uint64>`**: фиксирует начальное состояние хромосом генома.
- **`TUX_TIME=<секунды>`**: фиксирует системное время (позволяет обходить проверки выходных дней и замораживать временные метки).
- **`TUX_CPU_TEMP=<float>`**: фиксирует температуру процессора (предотвращает `TR_GLOBAL_WARMING`).
- **`TUX_LUCKY=1`**: гарантирует выживание в русской рулетке.
- **`TUX_FORCE_ARCH=1`**: эмулирует окружение Arch Linux.
