# Урок 4: Память с произвольным доступом (`mem[]`)

Помимо статических переменных `vars[N]`, виртуальная машина TuxPL предоставляет динамическую память `mem[]` с произвольной адресацией по указателям.

---

## 1. Команды работы с `mem[]`

| Команда | Опкод | Описание | Состояние стека |
| :--- | :--- | :--- | :--- |
| `TuUX` | `LOAD_IND` | Снимает адрес $addr$ со стека и кладет значение `mem[addr]` | `addr` $\to$ `mem[addr]` |
| `TUux` | `STORE_IND` | Снимает значение $val$, затем адрес $addr$, и записывает `mem[addr] = val` | `addr, val` $\to$ *(пусто)* |

> [!CAUTION]
> Порядок аргументов при `STORE_IND`: сначала на стек кладется адрес $addr$, затем значение $val$.

---

## 2. Запись 42 в mem[7] и чтение:

```tux
{: TuuUUUX	TuuUuUuUuX	TUux  TuuUUUX	TuUX;
{: tUUx;
```

1. `TuuUUUX`: PUSH 7 (адрес)
2. `TuuUuUuUuX`: PUSH 42 (значение)
3. `TUux`: STORE_IND $\to$ `mem[7] = 42`
4. `TuuUUUX`: PUSH 7
5. `TuUX`: LOAD_IND $\to$ читает `mem[7]`
6. `tUUx`: PRINT_NUM $\to$ печатает 42.
