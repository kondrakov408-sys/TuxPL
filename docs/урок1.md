# Урок 1: Архитектура TuxPL и первый вывод

Добро пожаловать в TuxPL. Это эзотерический стековый язык, в котором все команды состоят исключительно из букв `T/t`, `U/u` и `X/x`.

Интерпретатор беспощаден: при малейшей ошибке в синтаксисе, разделителях или операциях со стеком он выдает ехидный троллинг без указания строки и символа. Поэтому правила нужно соблюдать неукоснительно.

---

## 1. Строгая структура строки

Любой исходный код `*.tux` подчиняется жестким правилам:

1. **Обрамление строки:** каждая строка начинается с `{: ` и заканчивается `;`.
2. **Пробел после открытия:** сразу после `{: ` идет **ровно один пробел**.
3. **Прижатая точка с запятой:** символ `;` прижимается вплотную к последней команде строки без пробелов (например: `tUX;`).
4. **Динамический разделитель:** пробел между соседними командами зависит от количества букв `U/u` в **левой** (предыдущей) команде:
   - 1 буква `U/u` → **1 пробел** (` `)
   - 2 буквы `U/u` → **2 пробела** (`  `)
   - 3 буквы `U/u` → **3 пробела** (`   `)
   - 4 и более букв `U/u` → **один символ табуляции** (`\t`)

---

## 2. Анатомия команды

Каждая команда имеет форму:
```
T/t + [последовательность U/u] + X/x
```

### Банк A (ровно одна буква U/u) — операции стека и арифметика
Операндов нет. Все аргументы берутся прямо со стека.

| Команда | Операция | Описание |
| :--- | :--- | :--- |
| `tux` | DUP | Дублировать вершину стека |
| `tuX` | SWAP | Поменять местами два верхних элемента ($a, b \to b, a$) |
| `tUx` | POP | Удалить верхний элемент со стека |
| `tUX` | PRINT_CHAR | Вывести символ по ASCII-коду (младший байт вершины) |
| `TuX` | ADD | Сложить ($a + b$) |
| `Tux` | SUB | Вычесть ($a - b$, где $b$ — вершина стека) |
| `TUx` | MUL | Умножить ($a \times b$) |
| `TUX` | DIV | Разделить нацело ($a / b$). Деление на 0 карается троллингом! |

### Банк B (две и более буквы U/u) — операнды и память
Первые две буквы `U/u` определяют операцию, а **хвост** задает числовой аргумент $N$ в двоичной системе:
- `u` = `0`
- `U` = `1`
- Пустой хвост = `0`
- Старший бит идет первым

Пример: опкод `PUSH` имеет префикс `Tuu...X`.
- `TuuX` $\to$ хвост пуст $\to$ `PUSH 0`
- `TuuUX` $\to$ хвост `U` ($1_2$) $\to$ `PUSH 1`
- `TuuUuX` $\to$ хвост `Uu` ($10_2$) $\to$ `PUSH 2`
- `TuuUuUX` $\to$ хвост `UuU` ($101_2$) $\to$ `PUSH 5`

## 3. Практика: пишем первый символ

Выведем восклицательный знак `!`.
ASCII-код `!` равен $33$.
Переводим $33$ в двоичную систему:
$$33 = 32 + 1 = 100001_2$$

Собираем команду:
- Базовый префикс и суффикс `PUSH`: `Tuu...X`
- Хвост двоичных бит: `100001` $\to$ `UuuuuU`
- Итоговое слово: `Tuu` + `UuuuuU` + `X` = `TuuUuuuuUX`

Считаем количество букв `U/u` в слове `TuuUuuuuUX`:
`u` + `u` + `U` + `u` + `u` + `u` + `u` + `U` = **8 штук**.
Так как букв `U/u` $\ge 4$, разделителем после этой команды должен быть **символ табуляции (`\t`)**!

Следующая команда — `tUX` (`PRINT_CHAR`). В ней ровно 1 буква `U`. Она последняя в строке, поэтому к ней сразу прижимается `;`.

Получаем исходник:
```tux
{: TuuUuuuuUX	tUX;
```
*(между `TuuUuuuuUX` и `tUX` стоит знак табуляции)*

---

## 4. Сборка и запуск

Запусти через классический флаг `--PLS`:
```bash
./tuxpl --PLS ex1.tux
```
Вывод:
```text
!Tux approves.
```
