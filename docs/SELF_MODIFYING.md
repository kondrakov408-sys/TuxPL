# Самомодификация, эволюция и старение кода в TuxPL 2.0.0

## 1. Концепция живого кода

В TuxPL 2.0.0 код программы не является статическим текстом: это биологическая среда, непрерывно изменяющаяся в процессе исполнения.

## 2. Фаза мутации ячейки (`tux_mutate_cell`)

После выполнения каждой инструкции ячейка памяти подвергается эволюционной обработке:
1. `exec_count++`: увеличивается внутренний счётчик исполнений.
2. **Старение инструкции**:
   - После 3 исполнений возраст переходит на следующую стадию:
     $$\text{YOUNG} \to \text{ADULT} \to \text{OLD} \to \text{DEAD}$$
   - При переходе в `DEAD`: ячейка необратимо помечается флагом `TUX_FLAG_CORRUPTED`, а декодер навсегда превращает её в `OP_NOP`.
3. **Мутация кода**:
   - Если ячейка не защищена флагом `TUX_FLAG_IMMUTABLE`:
     $$\Delta = \text{tux\_crazy64}(\text{result}, \text{entropy\_pool})$$
     $$\text{cell.val} \oplus= (\Delta \pmod{256})$$
     $$\text{cell.raw\_code} = \text{mutation\_encode}(\text{cell.val}, \text{program\_key}, G_0)$$
     $$\text{cell.flags} \ |= \text{TUX\_FLAG\_MUTATED}$$

## 3. Клонирование ячеек (`OP_CLONE`)

Команда `OP_CLONE` копирует ячейку `src` по адресу `dst`:
- Поколение клона увеличивается: `dst.gen = src.gen + 1`.
- Лимит поколений: при достижении `gen == 255` поколение насыщается и рантайм вызывает `troll_die(TR_AGE)` («ПРЕДЕЛ ПОКОЛЕНИЙ»).
- Лимит активных исполняемых ячеек в 64K-памяти: `TUX_MAX_ACTIVE_CODE = 16384`. Превышение лимита $\implies$ `troll_die(TR_MEMRANGE)`.

## 4. Спящий код и резонанс генома (`Dormant Resonance`)

- Ячейки с флагом `TUX_FLAG_DORMANT` игнорируются декодером и безопасно выполняются как `OP_NOP`.
- Пробудить ячейку можно явно инструкцией `OP_WAKE <addr>`.
- На фазе 6.1 рантайм проверяет фоновый резонанс генома:
  $$(\text{Genome}[3] \oplus \text{addr}) \pmod{256} == 0$$
  При совпадении гармоники ячейка спонтанно просыпается (`TUX_FLAG_DORMANT` снимается).

## 5. Синтез кода из данных (`OP_STOREIND`)

Запись значения в память через `STOREIND` выполняет автоматическое кодирование:
$$\text{memory}[a]\text{.raw\_code} = \text{mutation\_encode}(v, \text{program\_key}, G_0)$$
$$\text{memory}[a]\text{.flags} \ |= \text{TUX\_FLAG\_MUTATED}$$

При переходе по данному адресу рантайм-декодер на лету синтезирует из записанного значения полноценную исполняемую инструкцию.
