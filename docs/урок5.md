# Урок 5: Списки (`lists[]`), отладка и дзен TuxPL

В финальном уроке мы разберем динамические списки (векторы), а также систематизируем типичные ошибки и правила отладки в условиях жестокого троллинга со стороны компилятора и VM.

---

## 1. Команды для работы со списками

В TuxPL есть массив списков: `lists[0]`, `lists[1]`, ... Номер списка $N$ задается прямо в команде в виде двоичного хвоста.

| Команда | Опкод | Действие | Аргументы стека |
| :--- | :--- | :--- | :--- |
| `tuux` | `LIST_NEW N` | Создать или очистить список №$N$ | — |
| `tuUx` | `LIST_PUSH N` | Добавить элемент в конец списка №$N$ | `val` $\to$ *(пусто)* |
| `tuUX` | `LIST_GET N` | Получить элемент по индексу $i$ из списка №$N$ | $i \to$ `val` |
| `tUux` | `LIST_SET N` | Записать значение $val$ по индексу $i$ в список №$N$ | $i, val \to$ *(пусто)* |
| `tUuX` | `LIST_LEN N` | Получить текущую длину списка №$N$ | *(пусто)* $\to len$ |

## 2. Чек-лист выживания при ошибках компилятора

| Категория ошибки | Что реально пошло не так | Как исправить |
| :--- | :--- | :--- |
| **TR_CURSED_NAME** | Имя файла не равно числу бит | Переименуй в `<размер_в_байтах * 8>.tux` |
| **TR_CURSED_WEEKEND** | Сегодня суббота или воскресенье | Подожди понедельника или передай `TUX_WAKE_UP=1` |
| **TR_CURSED_NON_ARCH** | Не Arch-based система | Используй Arch, CachyOS, Manjaro или `TUX_FAKE_OS=arch` |
| **TR_CURSED_NO_LIB** | Нет импорта библиотеки | Подключи `<~"TUX"/['...']~>!` из `Tux/` |
| **TR_CURSED_LINE_CYCLE** | Нарушен цикл 1-2-3-4-5 | В строке $L$ должно быть ровно $((L-1) \bmod 5) + 1$ команд |
| **TR_CURSED_CHECKSUM** | Неверная буква T/U/X в конце | Пересчитай битовую делимость префикса строки |
| **TR_MATH_DEATH** | Ошибка в математическом опросе | Решай пример правильно, иначе `unlink` сожжет файл |
| **TR_STACK** | Снятие с пустого стека | Проверь баланс `PUSH`/`POP` |
| **TR_DIVZERO** | Деление на 0 | Проверь делитель |
