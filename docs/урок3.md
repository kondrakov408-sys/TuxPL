# Урок 3: Управление потоком, метки команд и циклы

В TuxPL нет именованных меток и операторов `while` или `for`. Все переходы осуществляются по **абсолютному порядковому номеру команды** во всем файле, начиная с `0`.

---

## 1. Команды ветвления и перехода

| Команда | Опкод | Описание |
| :--- | :--- | :--- |
| `TUuX` | `JMP N` | Безусловный переход на команду с глобальным номером $N$ |
| `TUUx` | `JZ N` | Снимает вершину стека; если она равна $0$, прыгает на команду $N$ |
| `TUUX` | `JNZ N` | Снимает вершину стека; если она не равна $0$, прыгает на команду $N$ |
| `tuuX` | `CMP` | Снимает $b$, затем $a$. Если $a < b \to -1$, $a == b \to 0$, $a > b \to 1$ |

> [!IMPORTANT]
> Если прыгнуть на номер команды, в точности равный общему количеству команд в файле (т.е. за пределы последней команды), программа корректно завершается!

---

## 2. Карта команд цикла (`examples/loop.tux`)

Программа печатает `54321`:

| Индекс | Команда TuxPL | Опкод и аргумент | Действие |
| :---: | :--- | :--- | :--- |
| **0** | `TuuUuUX` | `PUSH 5` | Кладем 5 на стек. |
| **1** | `TuUx` | `STORE 0` | Сохраняем 5 в `vars[0]`. |
| **2** | `Tuux` | `LOAD 0` | **Начало цикла.** Загружаем счетчик. |
| **3** | `TUUUuUUx` | `JZ 11` | Если 0 $\to$ прыжок на 11 (выход). |
| **4** | `Tuux` | `LOAD 0` | Загружаем счетчик для печати. |
| **5** | `tUUx` | `PRINT_NUM` | Печатаем значение счетчика. |
| **6** | `Tuux` | `LOAD 0` | Загружаем счетчик для декремента. |
| **7** | `TuuUX` | `PUSH 1` | Кладем 1 на стек. |
| **8** | `Tux` | `SUB` | `счетчик - 1`. |
| **9** | `TuUx` | `STORE 0` | Сохраняем обратно в `vars[0]`. |
| **10** | `TUuUuX` | `JMP 2` | Прыжок на команду 2. |

Запуск:
```bash
./tuxpl --PLS examples/loop.tux
```
Вывод: `54321`
